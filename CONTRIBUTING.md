# Contributing

1. Keep file preparation separate from machine commands.
2. Add offline tests for changed geometry, configuration and movement checks.
3. Do not remove authentication, reference checks or stop conditions.
4. Use synthetic fixtures in tests.
5. Exclude local machine records and credentials from commits.
6. State which checks passed and which physical checks remain open.

Interface text uses short instructions and consistent technical names.
The writing target is ASD-STE100 Simplified Technical English.
Full vocabulary compliance needs review against the official dictionary.
Do not add promotional claims or generated praise.

A software test is not physical machine qualification.
